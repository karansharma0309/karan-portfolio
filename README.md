# Karan Sharma Portfolio

A responsive portfolio website built with plain HTML, CSS and JavaScript.

## Structure

- `index.html` - main page
- `css/style.css` - main styling
- `css/responsive.css` - mobile/tablet styling
- `js/script.js` - menu, animations, navigation and contact form
- `assets/logo.png` - portfolio logo
- `assets/profile.png` - profile image
- `resume/Karan_Sharma_CV.pdf` - add your real CV here

## Before deployment

1. Replace `your-email@example.com` with your real email.
2. Replace `#` project GitHub/Live Demo links.
3. Put your real CV at `resume/Karan_Sharma_CV.pdf`.
4. Verify GitHub and LinkedIn URLs.
5. Open `index.html` locally and test all links.

## Deployment

This is a static website, so it can be deployed directly to GitHub Pages, Netlify or Vercel.

No build command is required.
